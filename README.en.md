# 小纸 (InkPaper)

InkPaper is an Android note-taking app for personal knowledge capture. Local note-taking is recommended, and you can also connect to a self-hosted Memos server for sync. The app supports Memos-compatible Markdown, images, tags, reminders, search, WebDAV backup, import/export, system sharing, widgets, and optional AI-assisted writing.

[Latest release](https://gitee.com/liudengxing233/ink-paper/releases/latest) · [GitHub repo](https://github.com/liudengxing/InkPaper) · [Issues](https://github.com/liudengxing/InkPaper/issues) · [中文](README.md)

## Features

- Local notes, official server sync, and self-hosted Memos sync.
- Markdown rendering, todos, links, images, and tags.
- Hierarchical tags such as `#work/projectA`.
- Full-text search, pinning, reminders, and random review.
- Image upload, preview, saving, and multi-image browsing.
- WebDAV backup and restore, with optional image backup.
- Import from Flomo, WeRead, and other sources.
- Android system share targets.
- Quick-note and random-review widgets.
- AI-assisted writing and custom prompts.
- Chinese and English UI.
- Android only: releases ship as APK and AAB.

## Download

Release assets are published on [Gitee Releases](https://gitee.com/liudengxing233/ink-paper/releases) (recommended from mainland China) and mirrored to [GitHub Releases](https://github.com/liudengxing/InkPaper/releases); both carry the same files.

GitHub is slow to reach from mainland China, so CI mirrors the repository and the APK to Gitee (the AAB stays on GitHub). The in-app update check reads Gitee only. To clone from the mirror:

```bash
git clone https://gitee.com/liudengxing233/ink-paper.git
```

Android APKs on GitHub Releases are for manual installation and test distribution; Google Play submission uses the signed AAB generated by the release workflow.
The repository keeps the Android platform only and has no other build targets.

## Development

After installing Flutter:

```bash
flutter pub get
dart tool/inkpaper.dart verify
```

Common commands:

```bash
dart tool/inkpaper.dart doctor
dart tool/inkpaper.dart analyze
dart tool/inkpaper.dart test
dart tool/inkpaper.dart store-check
dart tool/inkpaper.dart build android-debug
dart tool/inkpaper.dart build android-release
```

Builds need the Android SDK (see "Android environment" below) and JDK 17.

### Android environment

1. Install the [Android command-line tools](https://developer.android.com/studio#command-tools) and set `ANDROID_HOME` to the SDK directory.
2. Install components via `sdkmanager`:

```bash
sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"
sdkmanager --licenses
```

3. Make sure `adb` (under `$ANDROID_HOME/platform-tools`) is available. Connect a device or start an emulator, then run `flutter run`.

## Release

The app version is managed in `pubspec.yaml`, where `x.y.z` is the semantic version and `+N` is the build number:

```yaml
version: 1.1.84+10180
```

Bump both the `x.y.z` patch and `+N` on every change, and update the `x.y.z` shown in the "Current Version" section above — `dart tool/inkpaper.dart store-check` asserts that the two match and fails otherwise.

Release command:

```bash
dart tool/inkpaper.dart release v1.1.84
```

The command first checks that the tag matches `pubspec.yaml`, then creates and pushes the tag. GitHub Actions verifies, builds, and publishes the Android APK/AAB.
