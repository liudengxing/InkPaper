## A. 删除笔记（R-01 `4deaa41` · R-08 本轮改造）

- [ ] 侧滑卡片点「删除」，或「⋯」菜单点「删除」，**先弹确认框**（不再直接删）
- [ ] 确认框是窄长的一条：标题「删除笔记」，正文「是否确认删除，删除笔记会移至回收站，30 天内可以前往回收站恢复」，按钮「取消 / 删除」
- [ ] 点「取消」什么都不发生
- [ ] 点「删除」后，这一行**从右往左滑出去**并淡出，下面的卡片平滑补位（不是硬跳一格）
- [ ] 底部弹的是原生提示条（贴底、深色一条），写「笔记已删除」，约 2 秒消失
- [ ] 从点开菜单到这一行消失，全程没有可感知的停顿
- [ ] 连续删三条，每条都滑出、都有提示条，不卡顿
- [ ] 删除后下拉刷新，被删的不会「复活」
- [ ] 删错了去「最近删除（回收站）」能找回，30 天内有效
- [ ] 详情页 / 标签页里删除同样先确认，标签页删完列表正常刷新

## B. AI 洞察（R-02 · `4b954a6` + `1339769` + `e7677b9`）

- [ ] 页面底色是浅灰 #F9F9F9，卡片纯白 12dp 圆角、无描边
- [ ] 「分析范围」是一行：左侧图标+文字，右侧当前值+箭头，点开是底部选择器
- [ ] **视角是一行一条**（36dp 图标 → 标题+描述 → 右侧箭头），不是 2×3 方块
- [ ] 六个内置视角 + 「新建视角」一屏放得下，描述不被截断、不换行挤压
- [ ] 行里**没有**「by InkPaper」字样（自定义视角也只需要看标题）
- [ ] 「已改」标记是一个小圆点，不是色块
- [ ] 长按任一行能查看 / 修改提示词
- [ ] 点视角后生成态：左对齐转圈 + 骨架条 + 视角说明，不是居中大转圈
- [ ] 出结果后：小标签 → 21sp 标题 → 短线 → 正文；正文里 `[n]` 引用可点
- [ ] 结果页底部是一个主按钮 + 两个文字按钮，没有一排并列按钮
- [ ] 选择 → 生成 → 结果之间是淡入 + 轻微上移，不闪白

## G. AI 设置 / DeepSeek（`8998fa4` + `1826cf4`）

- [ ] 设置 → AI 设置 → DeepSeek 预设：API 地址是 `https://api.deepseek.com`，**结尾没有 `/v1`**
- [ ] 之前存过 `/v1` 的老配置，进页面后自动变成不带 `/v1`（自定义服务商不受影响）
- [ ] 模型可选 `deepseek-flash`（默认）与 `deepseek-v4-pro`
- [ ] 粘贴带空格 / 引号 / `Bearer ` 前缀的 key，点「测试连接」能成功（会自动清洗）
- [ ] key 里混进中文或全角字符时，提示说的是「密钥含非法字符」，不是「网络请求失败」
- [ ] key 真填错时，弹出的是**详情弹窗**：地址、模型、密钥长度与末四位、服务端原文
- [ ] 测试连接不再因为「思考模式吃掉 token」而误报失败
- [ ] 保存后回到笔记页用一次 AI 功能，能正常出内容
