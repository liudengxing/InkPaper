# 1.1.122 真机验收清单

> 本轮针对 5 条口述需求。装的是 **1.1.122+10222**（arm + arm64、已混淆）。
> 上一版的功能验收仍看 `VERIFY_1.1.121.md`。

## I. AI 洞察：截断与推理过程

- [ ] 打开 AI 洞察 → 选任意视角，生成过程**不再只转圈**：应该先出现「正在推理…」，下面是逐行增长的思考文本
- [ ] 思考结束后自动出现「正在落笔」+ 正文流式增长
- [ ] 生成完成后，结果页标题下方有一块「推理过程 · N 字」，默认收起，点一下能展开、再点收起
- [ ] 输出不再报「输出被 max_tokens 截断（finish_reason=length）」
- [ ] 若真的被截断（长笔记 + 长思考），会自动重试，不会直接给一个空结果
- [ ] 换成第三方 OpenAI 兼容网关（不支持 SSE）时，仍然能正常出结果（只是没有实时思考）

## J. 搜索过渡

- [ ] 点右上角搜索：输入框出现时**不再上下弹一下**，位置一次到位
- [ ] 退格/取消回到标题，同样不跳
- [ ] 输入文字、清除、再取消，标题与三个图标完整（抽屉按钮不会消失）

## K. 详情页字数与图片

- [ ] 打开只有一张图的笔记：字数应是 0（或只有文字部分），不再是 90 多
- [ ] 打开一段文字 + 几张图的笔记：字数只算文字，底部显示「38 字 · 4 张图」这种形式
- [ ] 正文下方图片九宫格正常显示，点开能进查看器，长按能保存
- [ ] 纯文字笔记底部只显示「xx 字」，没有多余的「0 张图」

## L. 首页三个胶囊

- [ ] 冷启动进首页：顶部**只有标题**，看不到 AI 洞察 / 周期回顾 / 随机回顾
- [ ] 第一次下拉：三颗胶囊出现（同时不刷新笔记）
- [ ] 第二次及以后下拉：不再出现在胶囊上，而是正常刷新笔记
- [ ] 切到别的页面再回来，胶囊还在（同一次运行内）
- [ ] 重启 App 后恢复成默认隐藏，需要再下拉一次
- [ ] 搜索态下胶囊不显示，退出搜索后回来

## M. 周期回顾提示词

- [ ] 周期回顾 → 「重新生成」，文案明显更具体：会点出日期/具体写了什么，不再「首先/其次/最后」
- [ ] 不再出现「成长」「复盘」「闭环」「情绪价值」这类词
- [ ] 周回顾偏「这几天节奏与情绪」，月回顾偏「反复出现的主题和变化」
- [ ] 篇幅 280–380 字，分段 3–5 段，没有 Markdown 符号

## N. 随机回顾页

- [ ] 列表右上角提示是纯文字「下拉换一批」，没有箭头图标
- [ ] 右上角只有一个齿轮，**灰色**（不是绿色），没有随机/换一批按钮
- [ ] 下拉换一批：整批换掉，不和上一批重复
- [ ] 点齿轮打开设置：标题右侧写「选择即保存」，**没有「完成」按钮**
- [ ] 面板高度跟着内容走，标签少时不会留一大片空白

## O. 回顾设置

- [ ] 时间范围可选：7 天 / 30 天 / 180 天 / 365 天 / 自定义
- [ ] 选「自定义」会打开日期区间选择器，选完显示成「10.1 - 10.20」，最后一天整天算进去
- [ ] 笔记数量可选，改动后直接生效（关掉面板列表就变了）
- [ ] 标签区右上角有搜索框，输入能实时筛标签；搜不到显示「没有匹配的标签」
- [ ] 标签比之前多（库里 tags 字段里的标签也算进来了）
- [ ] 标签顺序按「最近 + 最常用」，不是字母序
- [ ] **没有全选/清空按钮**
- [ ] 点标签立即变色（选中），关掉面板后列表按标签过滤
- [ ] 关掉面板后，列表按新设置重算一批

## 已知遗留（本轮没动）

- AI 洞察没有拆成「选视角 / 看结果」两步页面
- 搜索框聚焦时仍有主题绿边
- 伪 UTC 跨源 8 小时窗口内的排序错位
